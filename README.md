# Red Sox GM Hub
Static front-office + fan hub for the Boston Red Sox. `index.html` reads `data/*.json`, refreshed by GitHub Actions
(full refresh ~7 AM ET, news/rumors/transactions ~7 PM ET). Sources: MLB Stats API, ESPN, MLB.com RSS, MLB Trade Rumors RSS.
Hand-maintained (cited) files: `data/contracts_manual.json`, `data/calendar_manual.json`, `data/franchise_manual.json`.
Unofficial personal project; not affiliated with MLB or the Boston Red Sox.
